## 数据与奖励

1,083 个正式 RL 训练字段中，有 402 个来源既未参与此轮 Planner SFT，也未参与 Scale1169 训练。开发字段来自五张整表，与本轮训练字段的表名无重叠。小试覆盖 32 个字段，每个字段采样四次。其中 14 个字段有对有错。正式训练每批 8 个字段，每个字段用当时的策略重新采样四次，共 512 条轨迹。

正式训练的 128 个字段中，47 个四次采样有对有错，能提供组内优劣信号。其余 28 个四次全对，53 个四次全错。

使用已评估的 Qwen3.5-9B 学生 Planner 初始化可训练策略和冻结的参考策略。分类 Skill 使用 Scale1169。合法终止且类别、等级均匹配得 1 分。检索排名和证据引用还可获得过程分，各批断点保存了每条轨迹的分数。推理只接收公开字段元数据和已取得的证据。训练使用 M9 入口，学习率为 5×10⁻⁶。

## 保存与复核

完成 16 个批次，其中 16 个实际改变参数。每批原子保存权重、AdamW 状态、随机状态和续训位置。首次有效更新后实际退出训练进程，后续有 15 次从前一批检查点恢复的记录。已核对全部 1226 条采样及评估结果与原始轨迹。

Windows 同步任务在连接恢复后补下载断点并验证文件哈希。512 条正式训练轨迹中有 2 条耗尽单次生成的 token 配额且未输出结束符，按未完成计 0 分，保留已生成的 token。另有 0 条正式训练轨迹曾触发检索输入长度限制，执行器按原有工具失败反馈继续处理。因整段上下文容量耗尽而结束的有 0 条，因模型调用预算耗尽而结束的有 0 条。服务故障单独处理。
