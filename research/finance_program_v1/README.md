# Finance Program：non-training 与第一版 Planner SFT

本目录保留 non-training、教师轨迹采集、第一版学生 Planner SFT 的代码，以及完整金融 **Val422** 的同接口配对评估结果。它是独立研究快照，不替换仓库原应用。

## 完整 Val422 结果

两组均为 Qwen3.5-9B，在相同 F66 Program/Skill 框架、输入与执行预算下比较：

- **ProgSkill / `base`**：未微调 Planner，仍调用 Skill，**不是直接回答的纯 Base-LLM**。
- **DCG-SFT / `sft`**：只加载第一版 Planner SFT A；所有模型型 Skill 继续使用原始基座并禁用 adapter。

共 **422 个唯一配对、844 条正式轨迹**。失败与未终止均保留在每组 422 的分母内，双方无缺失。

## 验证与隐私边界

所有服务器阶段及完整回放成功退出；本机从各自解包目录再次完整回放，并逐 SHA 核验原始证据全部成员及 844 份正式轨迹。逐 ID 指标、配对统计和两种 Macro-F1 已独立重算。聚合 JSON 保留证据 SHA 依赖，但不发布私有目录和来源 ID。

公开轨迹只保留 Program、实际步骤状态、最终类别/等级与原 trace SHA；业务元数据、原始消息、推理文本和语义证据已脱敏。两组学生使用一致的顺序公开编号；无私有 ID 映射。它们**不是训练数据，也不是完整控制器回放输入**。教师轨迹保持不变。

这是开发验证集、单 seed，仅 8/12 类有支持，且来源可能共享表；不是独立 Test 或跨领域泛化结论。教育与钢铁数据集不在本轮结果内。该更新只替换结果展示和学生公开轨迹，不修改实验代码、权重或训练设置。

真实数据集、gold、权重、凭证和实验服务器地址均不上传。clone/import 不会启动任何训练、GPU 或 API 作业。复现说明见 [REPRODUCE.md](REPRODUCE.md)。
