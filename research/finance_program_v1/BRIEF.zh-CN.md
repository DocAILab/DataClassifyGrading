# 一分钟汇报稿

师兄，目前已经完成 non-training 基线，以及 teacher 轨迹到学生 Planner 的第一版 SFT 冷启动和评估闭环。

历史 non-training 的 P14 实验在固定 Val80 上联合正确 21/80、合法终止 69/80；它与后来的 F66 接口不同，所以不直接作为 SFT 提升的严格分母。

第一版 SFT 使用 200 个经过基本复核的唯一 teacher 来源，只监督实际 Planner Program JSON 和 EOS，不监督 Skill 回复或标签答案。学生是 Qwen3.5-9B，LoRA 训练 1 个 epoch、实际 13 次更新，最长约 2.24 万 token 不截断。

随后用同接口原基座和 SFT Planner 做了 Val80 配对对照，两组 Skill 均使用原基座。联合正确率从20%提升到45%，合法终止率从45%提升到100%，模型调用从552次降到320次。所有失败保留在80分母，完整轨迹已回放，标签只事后本地计分。

本次交付包含 non-training 和第一版 SFT 代码、测试、汇总结果，以及 200 条教师和 240 条基线/学生脱敏轨迹。原始业务数据和权重不放公开库。当前结论限于开发 Val80，不宣称独立 Test 泛化。
